# Comments Generator

Build and manage a reusable **pool of feedback comments** organised by assessment question
or criterion. During marking, click any comment to copy it to your clipboard, ready to
paste into a student's feedback.

---

## Overview

The Comments Generator stores its data in the database (unlike the other apps, which are
session-only). This means your comment pool persists between sessions and is shared with
any colleagues who use the same instance of the app.

---

## Concepts

| Term | Description |
|------|-------------|
| **Question** | A top-level category or criterion, e.g. "Code quality" or "Report structure". Questions are shown as tabs or sections. |
| **Row** | A single comment entry inside a question. Each row has a **label**, a **positive** phrasing, and a **negative** phrasing. |

---

## Using the comment pool

1. Go to **Comments Generator**.
2. The page lists all questions as tabs. Click a tab to see its comments.
3. Each row shows the label and two buttons — **positive** and **negative** phrasing.
4. Click the phrasing you want to use; it is copied to your clipboard instantly.
5. Paste into your feedback document.

---

## Managing questions

| Action | How |
|--------|-----|
| **Add a question** | Click **+ Add Question** and enter the question text. |
| **Edit a question** | Click the pencil icon next to the question heading. |
| **Delete a question** | Click the bin icon next to the question heading. All rows inside it are also deleted. |
| **Reorder questions** | Drag questions into the order you want; the new order is saved automatically. |

---

## Managing comment rows

| Action | How |
|--------|-----|
| **Add a row** | Click **+ Add Row** inside a question and fill in the label and both phrasings. |
| **Edit a row** | Click the pencil icon next to any row. |
| **Delete a row** | Click the bin icon next to any row. |

---

## Tips

- Keep **labels** short (e.g. "Variable naming") so the tab is easy to scan during marking.
- Write **positive** phrasings in the second person present tense: "Your code is clearly structured…"
- Write **negative** phrasings to be constructive: "The code would benefit from…"
- There is no undo — deletions are immediate. If you make a mistake, re-add the row manually.
