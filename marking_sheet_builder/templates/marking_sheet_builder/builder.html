📖 User Manual & Guide
Column Types Explained
  • Numeric mark: A column to input numerical grades (e.g. out of 50).
  • Rubric mark: Integrates with standard grade classifications (First, 2:1, etc.). You can select subdivisions (High/Low, High/Mid/Low) to fine-tune the classification. The smaller the category's maximum mark, the fewer subdivisions should be used to avoid overlapping values.
  • Information: Static columns to record non-marked values (e.g. "Notes", "Group ID").
  • Feedback comment: Dynamic text fields to input descriptive feedback for students. These are automatically aligned at the absolute end of the final sheet.
Interface Instructions
  • Drag & Drop Reordering: Drag any dynamic column by its handle (⋮⋮) at the top of its card to reorder it inside the worksheet.
  • Total Mark Validation: The sum of numeric and rubric column maxima must exactly match the "Total mark" field at the top. The builder will validate this before allowing the download.
  • Excel Formulas: The generated Excel workbook will feature built-in lookup tables and dynamic calculation formulas to sum points and compute percentages in real-time.
⚙️ Rubric Boundaries Percentage Editor

Customise the default percentage weights used to compute rubric boundaries inside your downloaded spreadsheet. These changes scale proportionally to the maximum marks of any rubric column. Marks are automatically rounded to the nearest integer that falls within the expected grade band. Note that the smaller the maximum mark of a category, the fewer subdivisions should be used to avoid duplicate values.
